# ChessCam — النسخة التجريبية 0.1

موقع شطرنج عربي للآيفون والأندرويد، يُظهر الكاميرا واللوحة الرقمية وتحليل المحرك **Stockfish 19 Lite (single-thread)**، ويقترح نقلات حقيقية باستخدام قواعد `chess.js`.

## الموجود حاليًا

1. لوحة رقمية كاملة تدعم النقلات القانونية والكش والتبييت والأخذ بالتجاوز وترقية البيدق والتراجع.
2. تحليل حي من محرك Stockfish حقيقي يعمل على الهاتف داخل Web Worker (بعد تثبيت الحزم وبناء الموقع).
3. كاميرا خلفية مباشرة باستخدام `getUserMedia` بعد منح الإذن.
4. تحديد أربع زوايا للرقعة يدويًا على صورة من الكاميرا.
5. اكتشاف نقلة **تجريبي**: يقارن ملامح مربعات الرقعة في صورتين ويقترح نقلة قانونية مناسبة. يجب مراجعة الاقتراح واعتماده يدويًا. وضع المراقبة التلقائية يُظهر الاقتراح بعد ثلاث ملاحظات متتالية ولا ينقل القطع تلقائيًا.
6. سجل النقلات بصيغة PGN يمكن نسخه.

## ما ليس موجودًا بعد

- **لا** يوجد حاليًا نموذج تعرّف مُدرَّب لتصنيف كل قطعة من صورة منفردة؛ لذا لا يستطيع النظام استنتاج أي وضعية عشوائية من الصفر.
- قد تفشل قراءة النقلة إذا اهتزت الكاميرا أو ظهرت اليدان أو تغير الضوء أو لم تكن الرقعة واضحة أو كانت النقلة أخذًا معقدًا. عندها يمكن إدخال النقلة يدويًا.
- ليس هناك ضمان للفوز أو دقة الرؤية، ولم يتم الاختبار على كاميرا آيفون حقيقية في هذه البيئة.
- ملف ZIP يحتوي على الشفرة المصدرية؛ يجب تنفيذ `npm install` و`npm run build` لتجهيز ملفات المحرك وتشغيلها على خادم آمن.

## التشغيل والتطوير

المطلوب: Node.js إصدار 20 أو أحدث + اتصال إنترنت **عند تثبيت الحزم**.

```bash
npm install
npm run dev
```

افتح `http://localhost:5173` على الكمبيوتر. الكاميرا تحتاج HTTPS عند فتح الموقع من الآيفون، باستثناء `localhost` في المتصفح على نفس الجهاز. التشغيل من رابط HTTP محلي على الآيفون لن يسمح عادةً بالوصول إلى الكاميرا.

لبناء نسخة نشر ثابتة:

```bash
npm run build
```

ارفع مجلد `dist/` إلى خدمة استضافة HTTPS (مثل Netlify أو Vercel أو Cloudflare Pages). وإذا كنت تنشر **من المستودع مباشرة** استخدم `npm run build` كأمر البناء و`dist` كمجلد الإخراج. يتم نسخ محرك Stockfish وأصول WASM تلقائيًا من حزمة npm أثناء `prebuild`.

## كيفية استخدام الكاميرا

1. افتح الموقع من رابط HTTPS على iPhone Safari، واضغط «تشغيل الكاميرا» واسمح بالوصول.
2. ثبّت الهاتف فوق الرقعة بحيث تكون مستقرة ومضاءة، واختر لونك (الأبيض أو الأسود) في اللوحة الرقمية.
3. اضغط «تحديد زوايا الرقعة» وحدد بالترتيب: الزاوية الظاهرة أعلى يسار الصورة، أعلى يمين، أسفل يمين، أسفل يسار.
4. جهّز الرقعة في وضعية المباراة الحالية **المطابقة للوحة الرقمية**. اضغط «حفظ الوضع الحالي» بعد إبعاد اليدين.
5. بعد كل نقلة حقيقية، اضغط «قراءة النقلة بالكاميرا» أو فعّل المراقبة التلقائية؛ راجع الاقتراح واعتمده لتحديث المحرك.
6. إذا دخلت نقلة يدويًا، تأكد أن الرقعة الفيزيائية تطابق اللوحة الرقمية، ثم اضغط «حفظ الوضع الحالي» مرة ثانية.

## تنبيهات تقنية

- معايرة الأربع زوايا تفترض أن الرقعة مربعة ظاهرة من الأعلى تقريبًا؛ الحساب الحالي تقريب ثنائي خطي وليس تصحيح منظور كاملًا.
- يقدّم Stockfish أفضلية قوية جدًا ضد معظم البشر، لكنه لا يضمن الفوز من كل موقف.
- عند توزيع المشروع، احترم تراخيص الحزم. تتضمن `stockfish` برمجيات مرخصة GPL-3.0؛ لا تحذف إشعارات حقوق النشر أو الرخص.
- ملفات الفيديو لا تُرسل إلى خادم في هذا التطبيق؛ التحليل المرئي يجري محليًا في المتصفح.

## التقنية

Vite + JavaScript + chess.js 1.4.0 + Stockfish 19.0.1 + Web Workers + MediaDevices API.
